# Godot x SpacetimeDB Demo
Uses Godot 4.4 Truck Town demo project with (Godot-SpacetimeDB-SDK)[https://github.com/flametime/Godot-SpacetimeDB-SDK] to connect to SpacetimeDB.
Runs the chat using the C# quickstart guide and has multiplayer position syncing.
